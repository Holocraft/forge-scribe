# Package listing copy

Foundry's AI content policy says the package description and marketing must be written by a human. Do not generate this file with an assistant and paste it into the listing.

`module.json` `description` is a placeholder on purpose. Replace it yourself before you submit the package, and keep that edit in a commit you can explain.

Suggested points to cover, in your own words:

- What a GM gets: journals and NPC actors from a PDF they already own.
- That the GM brings their own API key, and the PDF is not uploaded to us.
- That it targets Foundry v14 and dnd5e 6.
- That scenes, maps, and magic-item cards are not in this version.

Leave this file as notes. The listing text itself should not be drafted here by an automated tool.
